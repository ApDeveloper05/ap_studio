# 🚀 AP Studio

> **Aryan Parmar Studio**

AP Studio is an open-source developer platform focused on reducing repetitive development work by providing reusable authentication modules, project generators, automation tools, and enterprise-ready project architectures.

---

## 📌 Current Status

**Version:** `v0.1`

**Status:** 🟡 Under Development

---

## 🎯 Current Goal

Develop a reusable Django Authentication System with CLI support that can be integrated into any Django project within minutes.

---

## ✨ Features (v0.1)

- ✅ Reusable Authentication System
- ✅ Django Support
- ✅ CLI Support
- ✅ Email (SMTP) Integration
- ✅ OTP Verification
- ✅ Forgot Password
- ✅ Reset Password
- ✅ Enterprise Project Structure
- 🚧 GUI Support *(Coming Soon)*
- 🚧 AI Integration *(Coming Soon)*
- 🚧 Marketplace *(Coming Soon)*
